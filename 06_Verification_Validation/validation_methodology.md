# Validation methodology

## Verification

Verification is the numerical comparison of discretization levels and
convergence behavior.

Required evidence:

- residual histories
- force histories
- mesh-sensitivity results
- mesh-quality report
- documented boundary-condition and MRF implementation

## Validation

Validation requires comparison with traceable model-test data for B5-75
P/D = 1.20, EAR = 0.75, or a clearly identified different but measured
configuration.

The repository currently contains a published polynomial curve only. It is a
reference correlation, not raw experimental data.
