# Performance analysis

## Status

Reference data and analysis scripts are provided. CFD result files are not
present until `Allrun` succeeds.

## Scripts

- `performance.py`: calculate `J`, `KT`, `10KQ`, and open-water efficiency.
- `reference_comparison.py`: compare CFD coefficients with the B-series
  regression curve.
- `plotting.py`: generate performance and force plots.
