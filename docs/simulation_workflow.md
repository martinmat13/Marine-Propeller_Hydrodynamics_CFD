# Simulation workflow

1. Source and define the geometry.
2. Generate the reconstruction STL.
3. Create the background mesh.
4. Refine and snap the propeller surface.
5. Create the MRF cell zone.
6. Check mesh quality.
7. Solve the baseline operating condition.
8. Check residuals and force histories.
9. Extract coefficients.
10. Compare with reference data.
11. Repeat at operating points and mesh levels.
